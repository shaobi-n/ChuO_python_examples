# ChuO_python_examples

This repository contains examples of my past Python scripts.

• **Data Cleaning and Visualization Script:** Demonstrates how I retrieved data from an SQL database, performed data transformation, and used the transformed data to train a predictive model.

• **Qualtrics API Example:** Showcases an attempt to retrieve data from the Qualtrics API using Python, utilizing both POST and GET requests.

• **Data Cleaning Copy Script:** A script used for cleaning data in preparation for a CatBoost predictive model.
